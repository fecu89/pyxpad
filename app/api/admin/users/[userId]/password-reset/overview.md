# 관리자 비밀번호 초기화

`REVOKE_USER_SESSIONS` 권한으로 관리할 수 있는 아이디·비밀번호 계정에 무작위 임시 비밀번호를 발급합니다. 전체관리자·보조관리자 대상 작업은 최근 15분 안에 다시 로그인한 전체관리자만 수행할 수 있습니다.

새 scrypt 해시 저장, `mustChangePassword = true`, `authVersion` 증가, `USER_PASSWORD_RESET` 감사 로그 기록을 한 트랜잭션으로 처리합니다. 평문 임시 비밀번호는 응답에서 한 번만 보여주며 DB·감사 로그에는 저장하지 않습니다. 카카오 전용 계정과 자기 자신의 계정은 이 API로 초기화할 수 없습니다.
