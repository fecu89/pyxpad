# 보안 유틸 개요

`pii-crypto-core.ts`는 사용자 이메일·표시 이름·프로필 이미지 URL을 AES-256-GCM으로 암호화하고, 이메일 정확 검색용 HMAC-SHA-256 인덱스를 생성합니다. `pii-crypto.ts`는 앱에서만 사용하는 `server-only` 경계입니다.

- 모든 암호문은 사용자 ID와 필드명을 AAD로 사용합니다.
- 암호화 키와 검색 키는 서로 분리합니다.
- 키는 서버 환경 변수에서 지연 로딩하며 클라이언트 모듈에서 가져올 수 없습니다.
- 로그나 오류 응답에 암호문, 원문, 키를 포함하지 않습니다.
