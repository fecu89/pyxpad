# 게시물 작성 보조 개요

이 폴더는 게시물 작성기의 브라우저 상호작용을 기존 `post-composer.tsx`와 분리해 제공합니다.

작성 UI는 데스크톱에서 투명 배경의 우측 패널, 모바일에서 실제 `visualViewport` 높이를 따르는 전체화면으로 표시합니다. 모바일의 첨부 도구 막대는 작성 폼의 고정 하단 영역에 있어 키보드가 올라와도 그 바로 위에 남습니다.

- `use-post-draft.ts`는 제목과 본문을 700ms 간격으로 브라우저 `localStorage`에 자동 저장합니다.
- 서버 렌더와 첫 클라이언트 렌더는 항상 전달받은 초기값을 사용하고, 저장된 초안은 마운트 후에만 확인해 hydration 결과를 바꾸지 않습니다.
- 저장된 초안을 자동으로 덮어쓰지 않고 사용자에게 복구 또는 삭제 선택을 제공합니다.
- 작성 내용이 남아 있으면 `beforeunload`로 탭 닫기와 새로고침을 경고합니다.
- 게시물 저장이 성공하면 `markSaved`로 로컬 초안을 지워야 합니다.
- 첨부 `File` 객체는 브라우저 재시작 후 복구할 수 없으므로 이 초안에는 저장하지 않습니다. 첨부 상태는 `components/pad/attachments/overview.md`를 따릅니다.
- `link-preview-input.tsx`는 한 줄에 하나씩 최대 남은 첨부 수만큼 URL을 받아 `/api/link-preview`에서 동시에 3개씩 안전한 미리보기 DTO를 만듭니다. 성공한 링크는 게시물의 추가 대기 목록으로 옮기고 입력창을 비우며, 형식 오류·미리보기 실패·20개 첨부 한도를 넘은 링크만 입력창에 남겨 고칠 수 있습니다. 중복 URL은 자동 제외합니다.
- 링크 입력은 항상 `post-composer.tsx`의 `<form className="composer-form">` 안에서 렌더링되므로 자체 `<form>`을 두지 않습니다. 줄바꿈은 여러 URL 구분에 사용하고 `Ctrl/⌘ + Enter` 또는 `type="button"` 버튼으로만 추가해 바깥 게시물 폼이 뜻하지 않게 제출되지 않도록 합니다.

로컬 초안에는 사용자가 입력한 본문이 남을 수 있으므로 공용 기기에서는 저장 완료·취소 시 삭제할 수 있게 해야 합니다. 서버 동기화 초안은 보드 권한·보존 기간·개인정보 정책을 별도로 확정한 뒤 추가합니다.
