# 공개 랜딩 UI

`app/page.tsx`의 로그인 없는 공개 홈페이지를 담당합니다. 작업공간 데이터와 세션을 조회하지 않고, 검색 파라미터의 인증 오류·로그인 요청·안전한 내부 콜백 경로만 받아 `LandingPage`에 전달합니다.

- `landing-page.tsx`: Server Component로 브랜드 헤더, 소개, CSS 기반 패드 화면 예시, 기능·학생/교사 가입 흐름, 작업공간 CTA를 렌더링합니다. 비트맵 목업을 내려받지 않고 로그인·테마 버튼만 작은 Client Component로 두어 첫 화면 이미지와 JS 요청을 늘리지 않습니다.
- `landing.module.css`: 공개 화면 전용 반응형 스타일입니다. 앱의 역할 기반 색상 토큰만 사용하므로 전역 라이트·다크 테마를 그대로 따르고, 980px과 720px에서 각각 태블릿·모바일 구조로 재배치합니다.
- 로그인 버튼은 `HomeAuthActionsProvider`의 일반 로그인·회원가입·카카오 흐름을 재사용하고 성공 후 기본 목적지는 `/dashboard`입니다. `/b/...` 같은 보호 경로에서 `/?login=1&callbackUrl=...`로 온 경우 검증된 내부 경로를 유지합니다.

`/`는 브랜드와 서비스 설명을 위한 공개 경로이고, 로그인 후 “내 패드”는 `app/(dashboard)/dashboard/page.tsx`의 `/dashboard`입니다. 공개 랜딩에는 사용자별 정보나 공개 패드 목록을 서버에서 조회하지 않습니다.
