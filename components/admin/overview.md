# Overview

`/admin` 사용자·권한 관리 화면의 Client Component 모음입니다. 서버가 전달한 마스킹 DTO만 사용하며, 원문 개인정보는 사유를 입력한 일시 조회 응답으로만 화면에 표시합니다.

- 사용자 목록은 일반 로그인 아이디·카카오 이메일 정확 검색과 10·50·100명 오프셋 페이지네이션을 제공합니다. 역할·상태·학교·반/부서 필터는 선택 즉시 적용되며, 소속 선택지는 학생 반과 교사 부서로 나뉩니다. 역할·상태·학교·반/부서는 각 행의 드롭다운에서 즉시 저장하고, 학생 행의 compact 번호 입력으로 1~99번을 지정·변경·해제합니다. 일반 교사는 자기 학교 학생 번호만 수정하며 일괄 선택과 다른 행 작업은 비활성화됩니다.
- `학교 대시보드`는 학생·교사·학급 수와 번호/학급 미지정 학생만 보여주고 사용자 명부·소속 관리·학생 계정 발급으로 바로 연결합니다. 학교 하나를 고르면 코드·급별·지역·운영 상태를 같은 화면에서 관리합니다.
- 별도 학급·담임 메뉴는 두지 않습니다. 학급과 부서는 `소속 관리`에서 편집하고, 학생만 일괄 선택한 사용자 작업 막대에서는 다른 수정과 상호 배타적인 `반 이동`을 열어 도착 반의 빈 번호를 자동 배정합니다.
- 시스템 권한·학교 대표교사·개인정보 조회·세션 해제·비밀번호 초기화·회원 삭제처럼 드물거나 민감한 작업은 행마다 렌더링하지 않고 `⋯` 버튼을 누른 사용자 한 명의 모달에서만 처리합니다. Credentials 계정 초기화 시 무작위 임시 비밀번호를 한 번만 표시하고 세션을 모두 해제합니다.
- 현재 페이지에서 여러 회원을 골라 역할·상태·소속을 일괄 변경하거나, 전체관리자는 선택 회원을 일괄 삭제할 수 있습니다. 현재 로그인한 관리자와 권한 밖 대상은 서버가 제외하고 결과를 구분해 반환합니다.
- 전체관리자는 학교, 전체관리자·학교 대표교사는 반·부서를 관리합니다. 학교를 펼치면 학교 대표교사 영역과 `학생 학급(CLASS)`·`교사 부서(DEPARTMENT)` 영역으로 나뉩니다. 전체관리자는 활성 교사를 대표로 지정·해제하고, 학생 쪽은 연결선과 들여쓰기로 학교 → 학년 → 반 → 학생 위계를 보여줍니다. 인원 버튼은 마스킹 구성원을 20명씩 지연 조회하고 학급 학생마다 번호 입력을 제공합니다. 일반 교사도 자기 학교 구조와 구성원을 읽고 번호를 수정할 수 있지만 구조 편집 폼은 보이지 않습니다.
- `학생 계정 발급`은 소속 관리 아래의 독립 사이드바 메뉴입니다. `.xlsx` 양식 다운로드 → 3MB·최대 500명 명단 미리보기 → 충돌 확인 → 사유 입력 → 계정 발급 순서이며, 학교·학년·반과 사용자를 함께 생성합니다. 결과의 아이디·초기 비밀번호는 한 번 표시하고 UTF-8 CSV로 내려받을 수 있습니다.
- `교사 가입 요청` 메뉴는 전체관리자에게 모든 학교, 학교 대표교사에게 자기 학교 신청만 보여줍니다. 학교·부서·마스킹 로그인 식별자를 확인하고 3자 이상의 사유로 승인하거나 반려하며, 대기 건수는 사이드바 배지에 표시됩니다.
- 전체관리자는 작업 사유와 확인을 거쳐 소유 패드가 없는 회원을 단일 또는 일괄 삭제할 수 있습니다. 삭제는 `DELETED` 상태·세션 버전 증가·개인정보 제거로 처리하고 감사 로그를 남깁니다.

## 디자인 정합 (`adminExp` 검토 결과 반영)

`adminExp` 시안에서는 학교 지표·점검 목록·반 이동·학교 정보의 기능 구조만 가져왔습니다. 프로젝트에 필요하지 않은 전출·재적 상태·담임·정원·진급은 UI·API·DB에서 제거했습니다. 시안의 serif/newsprint 외형과 별도 탭 내비게이션은 복제하지 않고, `app/globals.css`의 공용 의미 토큰과 Pretendard, 기존 관리자 사이드바·카드·입력 규칙을 사용합니다. 좁은 화면에서는 표가 가로 스크롤되고 작업 영역이 한 열로 바뀌며 다크 모드도 같은 의미 토큰을 공유합니다.

보호자 연락처는 수집 목적·열람 범위·보존 정책이 현재 프로젝트에 없으므로 추가하지 않았고, 메일 제공자가 없는 상태에서 동작하지 않는 교직원 초대 UI도 만들지 않았습니다. 기존 교사 가입 승인과 학생 XLSX 계정 발급 흐름을 재사용합니다.
