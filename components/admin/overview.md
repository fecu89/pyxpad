# Overview

`/admin` 사용자·권한 관리 화면의 Client Component 모음입니다. 서버가 전달한 마스킹 DTO만 사용하며, 원문 개인정보는 사유를 입력한 일시 조회 응답으로만 화면에 표시합니다.

- 사용자 목록은 정확한 이메일 검색과 10·50·100명 오프셋 페이지네이션을 제공합니다. 역할·상태·학교·반/부서 필터는 선택 즉시 적용되며, 소속 선택지는 학생 반과 교사 부서로 나뉩니다. 역할·상태·학교·반/부서는 각 행의 드롭다운에서 즉시 저장하고, 서버 검증에 실패하면 원래 값으로 되돌립니다. 학생은 `학교 + CLASS`, 교사는 `학교 + DEPARTMENT` 조합만 저장할 수 있습니다.
- 시스템 권한·학교 대표교사·개인정보 조회·세션 해제·회원 삭제처럼 드물거나 민감한 작업은 행마다 렌더링하지 않고 `⋯` 버튼을 누른 사용자 한 명의 모달에서만 처리합니다.
- 현재 페이지에서 여러 회원을 골라 역할·상태·소속을 일괄 변경하거나, 전체관리자는 선택 회원을 일괄 삭제할 수 있습니다. 현재 로그인한 관리자와 권한 밖 대상은 서버가 제외하고 결과를 구분해 반환합니다.
- 전체관리자는 소속 관리 화면에서 학교를 추가·수정·삭제할 수 있습니다. 학교를 펼치면 `학생 반(CLASS)`과 `교사 부서(DEPARTMENT)`가 별도 카드와 생성 폼으로 나뉘며, 각 항목에 실제 소속 인원수가 표시됩니다. 서비스 초기 학교·반·부서 데이터는 삭제하지 못하도록 보호합니다.
- `교사 가입 요청` 메뉴는 전체관리자에게 모든 학교, 학교 대표교사에게 자기 학교 신청만 보여줍니다. 학교·부서·마스킹 이메일을 확인하고 3자 이상의 사유로 승인하거나 반려하며, 대기 건수는 사이드바 배지에 표시됩니다.
- 전체관리자는 작업 사유와 확인을 거쳐 소유 패드가 없는 회원을 단일 또는 일괄 삭제할 수 있습니다. 삭제는 `DELETED` 상태·세션 버전 증가·개인정보 제거로 처리하고 감사 로그를 남깁니다.

## 디자인 정합 (newDesign.html 검토 결과 반영)

`app/globals.css`의 `/* Admin */` 블록은 공용 의미 토큰(`--surface`, `--surface-strong`, `--line`, `--muted`, `--ink`, `--green`, `--danger` 등)을 사용합니다. 관리자 기능 전환은 상단 탭 대신 데스크톱의 고정 사이드 내비게이션을 사용하고, 좁은 화면에서는 같은 세로 메뉴가 콘텐츠 위로 이동합니다. 사용자 표·행 편집기·일괄 작업 막대·페이지네이션·소속 관리도 같은 카드와 입력 필드 규칙을 따릅니다. 토큰이 `:root[data-theme="dark"]`에서 재정의되므로 관리자 화면도 별도 색상 체계 없이 다크 모드를 공유합니다.
