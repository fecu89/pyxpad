실제 화면

전부 npm run db:seed로 채운 데모 학교·데모 계정 화면입니다. 실제 가입자 정보는 들어 있지 않습니다.

카드 옮기기손잡이를 잡고 다른 열로. 키보드로도 같은 동작이 됩니다. 열 옮기기섹션 헤더를 잡으면 주제 순서 자체를 바꿉니다.
내 패드 홈만든 패드와 최근 방문한 패드 패드 안섹션으로 나눈 주제와 카드 카드 작성사진·음성·파일·링크 첨부 카드 상세반응과 댓글로 이어지는 대화 패드 설정7개 탭 — 외형·권한·승인·멤버 관리자 센터계정·권한·소속과 감사 로그
Features

들어 있는 것

수업에서 바로 쓸 수 있도록, 보드 편집부터 개인정보 처리와 내보내기까지 한 저장소에 담았습니다.

역할과 권한

학생·교사·전체관리자 역할, 학교·학급 소속, 보드별 소유자/관리자/편집자/멤버/뷰어 권한, 서명된 세션 쿠키.

보드 편집

섹션·카드 생성/수정/정렬/소프트 삭제. 마우스는 거리, 터치는 지연 기준으로 활성화해 스크롤과 구분하고, 키보드 조작도 지원합니다.

보관함과 복구

삭제해도 30일간 보관함에서 복구. 작성자·소유자·관리자는 보존 기간과 무관하게 언제든 영구 삭제할 수 있습니다.

댓글 · 반응 · 멘션

답글 트리, 이모지 반응, 내부 사용자 멘션. SSE 기반 보드 이벤트로 새로고침 없이 반영됩니다.

첨부파일과 링크

스트리밍 업로드, 이미지 자동 WebP 변환·썸네일, Range 다운로드, 매직바이트 검증으로 위조된 파일 형식 차단.

세분화된 패드 설정

기본 정보 · 공개 범위 · 외형 · 게시물 필드 · 참여 및 첨부 권한 · 게시 승인/동결 · 멤버 역할까지 7개 탭.

안전한 콘텐츠 렌더링

react-markdown + rehype-sanitize로 학생이 올린 본문을 안전하게 렌더링합니다.

내보내기

CSV(수식 인젝션 방어)·XLSX·첨부파일 ZIP, 인쇄용 뷰, 발표 모드.

보안 기본기

CSRF same-origin 검사, DB 공유형 IP·계정별 로그인 제한, 인증 이벤트 집계, PII 암호화·마스킹, CSP 등 보안 헤더.

Quickstart

5분 설치

Node.js 20+와 PostgreSQL 14+가 필요합니다. Node·PostgreSQL을 처음 써본다면 README의 8단계 안내를 그대로 따라가세요.

  1. 내려받고 패키지 설치

    git clone https://github.com/fecu89/pyxpad.git
cd pyxpad
npm install

  2. PostgreSQL 준비

    Docker가 있다면 한 줄로 끝납니다. Supabase·Neon 같은 클라우드 DB를 써도 됩니다.

    docker run --name pyxpad-postgres \
  -e POSTGRES_USER=pyxpad -e POSTGRES_PASSWORD=pyxpad \
  -e POSTGRES_DB=pyxpad -p 5432:5432 -d postgres:16

  3. 환경 변수 채우기

    .env.example을 .env.local로 복사한 뒤 DATABASE_URL·AUTH_SECRET·PII 키를 채웁니다. 각 항목 설명은 README의 환경 변수 표에 있습니다.

    cp .env.example .env.local
openssl rand -base64 32   # AUTH_SECRET·PII 키 만들 때

  4. 스키마 적용하고 실행

    시드는 데모 학교와 teacher@pyxpad.demo·student@pyxpad.demo 계정을 만듭니다.

    npm run db:migrate
npm run db:seed
npm run dev               # http://localhost:3001
